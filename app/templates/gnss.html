Geodesia física

Estaciones GNSS retenidas

Las estaciones GNSS permiten observar cambios de posición en el tiempo. En este visor se usan seis estaciones retenidas para estimar velocidades medias y analizarlas de forma contextual junto con las anomalías gravimétricas.

¿Qué representa una estación GNSS?

Una estación GNSS registra posiciones a lo largo del tiempo. A partir de su serie temporal se puede estimar una velocidad media en las componentes Este, Norte y vertical.

Marco de referencia

Las velocidades se interpretan en el marco IGS20 / ITRF2020. Para la lectura sismotectónica del visor se usan principalmente como referencia cinemática regional.

Relación con gravedad

Las estaciones GNSS no “explican” directamente un punto gravimétrico. La integración se realiza por superposición espacial y proximidad contextual.

Lectura metodológica

Las velocidades GNSS se usan como apoyo para reconocer tendencias cinemáticas regionales. Su integración con las anomalías gravimétricas no implica una relación causal directa, sino una lectura contextual por proximidad espacial.

En el visor se trabaja únicamente con las estaciones retenidas para el análisis regional. La interpretación de lineamientos o zonas de interés estructural debe realizarse junto con información geológica y sismológica complementaria.
